This Repository contains two carefully selected machine learning datasets designed for few-shot learning scenarios.
All images were captured using different conventional mobile phones for a realistic and diverse representation.
Each image is custom-created, ensuring that none of them exist elsewhere on the Internet.
The following two datasets are provided:
### German Road Sign Dataset
This dataset contains a labeled set of images representing various traffic symbols commonly
found on German roads.
### Common Everyday Object Dataset
The second dataset contains a labeled collection of images representing objects commonly found in everyday life, both indoors and outdoors (e.g. bicycles, chairs, bottles).
This collection is derived as a subset of classes from the [COCO Dataset](https://link.springer.com/chapter/10.1007/978-3-319-10602-1_48).
